# SGP4 epoch implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Start SGP4 with a directly executable Piet PNG for near-Earth epoch TEME vectors.

**Architecture:** Reuse the stack assembler and geometric renderer, leaving the baseline PNGs untouched. Assemble WGS-72 un-Kozai initialization, generalized Kepler solving, J3 long-period and J2 short-period corrections into a separate PNG. Pinned upstream source and published vectors are test oracles only.

**Tech stack:** Piet, unmodified 64-bit npiet 1.3h, Node assembly/tests, Docker.

**Spec:** This document defines the first SGP4 milestone authorized by the user's request to begin SGP4. It does not implement time propagation.

## Global constraints

- Keep tag v0.2.0 and all existing executable behavior and tests intact.
- Runtime computation occurs entirely in `sgp4/epoch.png`.
- Inputs: mean motion (revolutions/day times 1e8), eccentricity times 1e7, inclination/RAAN/argument of perigee/mean anomaly in degrees times 1e4.
- Initial bounded domain: mean motion 6.5–17 rev/day, eccentricity 0–0.25, inclination 0–170 degrees, other angles 0–360 degrees. Reject a corrected period of 225 minutes or more, or an epoch radius below WGS-72 Earth radius.
- Output: status and TEME x/y/z in metres and vx/vy/vz in mm/s. Status 1 and six zeroes for unsupported or invalid input. No elapsed-time input: epoch only.
- Before implementation, fix tolerances at 20 m and 20 mm/s per component against published epoch vectors and a separately pinned implementation.
- Preserve failures and fixes in the development log. Do not relax thresholds to obtain a pass.
- Near-180-degree inclinations are outside this first domain because the J3 longitude coefficient requires finer precision near its singular denominator.

## Review focus

Missing tokens, invalid bounds, unsupported deep-space cases, zero/tiny eccentricity, and low-perigee epoch states must have explicit tests. Test the exact domain boundaries and the generalized Kepler correction clamp. Tests invoke the PNG; the reference code must not participate in assembly or execution.
